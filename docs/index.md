# Generative Art Vault

Research notes on generative art algorithms, artists, and techniques.
Maintained by Hermes alongside code experiments.

## Structure

- **[Artists](Artists/)**: Artist profiles — bio, key works, technique analysis
- **[Algorithms](Algorithms/)**: Algorithm deep-dives with code sketches
- **[Inspirations](Inspirations/)**: Notable works, exhibitions, links
- **[References](References/)**: Books, papers, tutorials
- **[Journal](Journal/)**: Exploration log by date

## About

This vault lives in a git repo paired with generative art coding practice.
The user writes code in `sketches/` (vsketch studies under `sketches/vsketch/`,
py5/Processing studies under `sketches/processing/`); Hermes writes the
documentation in `docs/`. Images from experiments are copied into `docs/images/` and
referenced from the relevant notes.
